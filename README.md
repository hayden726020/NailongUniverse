# 西安邮电奶龙大学 网站项目

原版参考：[重庆奶龙大学.com](http://xn--psszg58cm5ej12gtkr.com)  
当前版本：**西安邮电大学（XUPT）定制复刻版**

这是一个结合了**西安邮电大学**（西邮）视觉识别元素与“奶龙”二创风格的高质感单页趣味前端网站。

---

## 🏫 西安邮电大学定制信息

- **校名全称**：西安邮电大学（Xi'an University of Posts & Telecommunications）
- **建校年份**：1950 年（EST. 1950）
- **校训**：爱国 · 求是 · 奋进
- **特色**：四邮四电之一、邮电通信特色
- **主题色**：西邮标准蓝（`#02367f` / `#014a95`）
- **跳转目标官网**：[https://www.xiyou.edu.cn/](https://www.xiyou.edu.cn/)
- **校徽微标**：结合西邮四叶瓣雁塔邮电标志与奶龙抱臂霸气形象的高清矢量级定制徽标。

## 🎨 网站交互与动效亮点

1. **蓝幕入场动画（Loader）**
   - 西邮奶龙校徽盖章动效（Stamp）与能量扩散涟漪（Ripple）
   - 动态载入进度条与精确时间线匹配的百分比计数（0% ~ 100%）
   - 状态文案切换：“奶龙正在启动护送模式...” → “到站! 欢迎来到西安邮电奶龙大学”
   - 支持屏幕任意点击或按键盘快速跳过

2. **揭幕与视觉呈现**
   - 蓝幕上滑收起，伴随全屏五彩纸屑撒花（Confetti）特效
   - 古典证书风双层微边框 + 双色粒子环绕旋转的虚线轨道（Orbit）
   - 适配深色模式（Dark Mode）与无障碍减弱动效偏好（prefers-reduced-motion）

3. **核心功能**
   - **前往官网**：点击触发整页平滑上浮淡出离场过渡，随后自动跳转至西安邮电大学官网
   - **重播动画**：重新播放开屏盖章撒花特效
   - **群号复制**：支持一键复制 QQ 群号，并具备复制成功提示
   - **关于本站**：原生 `<dialog>` 毛玻璃弹窗，展示站点背景与西邮校训

## 🚀 本地运行与预览

### 方式一：直接双击打开
所有静态资源均已转换为相对路径，直接在文件管理器中双击 `index.html` 即可在浏览器中完整浏览。

### 方式二：本地 HTTP 服务
```powershell
python -m http.server 8080
```
访问：[http://localhost:8080](http://localhost:8080)
